# InternCircle Task 5: Web Scraper for Headlines & Quotes

## Project Overview
A Python web scraper that retrieves quotes and author names from a public demonstration website using HTTP requests and HTML parsing.

## Features
- Sends HTTP requests using the requests library
- Parses HTML using BeautifulSoup
- Extracts quotes and author names
- Handles network and HTTP errors
- Saves results to JSON and TXT files
- Displays extracted data in the terminal

## Technologies Used
- Python
- requests
- BeautifulSoup4
- JSON
- HTML parsing

## Installation
Install the required libraries:

`python -m pip install requests beautifulsoup4`

## How to Run
Execute the following command in the project directory:

`python main.py`

The scraper generates `quotes.json` and `quotes.txt` after a successful request.
